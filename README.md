# Hangman Spiel (React)

Ein klassisches Hangman-Spiel (Galgenmännchen), entwickelt mit React. Ziel ist es, das versteckte Wort zu erraten, bevor alle Versuche aufgebraucht sind.

## 🚀 Features

- Zufällige Wörter
- Eingabe per Tastatur oder Buttons
- Anzeige falscher Versuche
- Hangman-Grafik / Statusanzeige
- Gewinn- und Verliererlogik
- Neustart-Funktion
- Responsive Design

---

## 🛠️ Technologien

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- React Hooks (`useState`, `useEffect`)
